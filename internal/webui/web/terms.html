REMOTE SUPPORT TERMS

Attended support consent

Remote Assist is an attended support tool operated by Remote Assist Project. Only run the customer application when you are actively working with a Remote Assist Project technician you recognize.

What approval means

When you enter a valid temporary session code, the application identifies the assigned technician and shows the access being requested. Remote screen viewing and keyboard/mouse control begin only after you approve the session.

Administrator access

If administrator privileges are requested, Windows displays its normal User Account Control prompt. You must approve that prompt locally. The initial release does not automate or bypass the Windows secure desktop.

Ending support

You may end the support session by closing the customer application. The technician can also terminate the server-side session. Session codes are single-use and expire automatically.

Data handling

The initial release relays live screen frames and control events through the Remote Assist support server when connected. Screen frames are not intentionally recorded or stored by the server. Operational events such as session creation, consent, connection, disconnection, and termination are retained for support auditing.

Security

Do not share a support code publicly. A support code is only an enrollment code; after approval, the application uses a separate randomly generated session credential for the live connection.
